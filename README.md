# Khreor Fashion Website Terms and Conditions of Sale - Legal Page

A fully responsive, mobile-friendly legal sales terms page featuring a scroll-triggered interactive acceptance modal built specifically for **Khreor Fashion**.

---

## 🚀 Features

* **Clean & Professional Typography:** Designed for high legibility across all desktop and mobile viewports, featuring detailed South African E-commerce laws, CPA return exemptions, and POPIA privacy guidelines.
* **Scroll-Triggered End-of-Page Detection:** The interactive popup modal is locked until the user scrolls completely to the bottom of the document, ensuring they have finished reading the entire agreement before responding.
* **Smart Action Redirection:**
  * **Accept Terms:** Redirects users instantly to `https://khreorfashion.store/vendor-onboarding/`.
  * **Do Not Accept:** Redirects users back to the primary storefront at `www.khreorfashion.store`.
* **Mobile-First Responsive Layout:** Includes adaptive padding, responsive CSS media queries, touch-friendly CTA buttons, and a centered smooth-transitioning card overlay.
